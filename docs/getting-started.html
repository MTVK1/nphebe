Getting started

Install Nphebe and get to your notes in a few minutes.

Download and install

1

Download Nphebe

Download the current desktop release from the official Nphebe download page.

2

Install the application

Run the installer and follow the installation prompts for your operating system.

3

Launch Nphebe

Open Nphebe after installation. On first launch, create a local account or sign in if you already have one.

Nphebe does not require Google authentication. Account authentication is handled locally by the application.
