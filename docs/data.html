Data & storage

Nphebe is designed around local desktop data and user-controlled database backups.

Where is my data?

Your application data is maintained by Nphebe on the computer where the application is installed. The exact app-data folder can vary by operating system and release.

What is the database file?

The database is the file Nphebe can export and import through its data-management features. It can be used as a backup and as a way to move your Nphebe data to another installation.

Important: Treat a database backup as sensitive. Store it somewhere private and secure, especially if your notes contain personal or confidential information.
