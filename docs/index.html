Nphebe Documentation

Everything you need to get started and keep your Nphebe data safe.

Core idea: Nphebe uses local authentication and gives you a way to export and import your database. Regular backups are the best way to protect important notes.

Quick start

1

Install

Download Nphebe and install the desktop application on your computer.

2

Create an account

Create your local Nphebe account using the account details requested by the application.

3

Create notes

Use Nphebe normally. Your application data is maintained by the desktop application.

4

Make a backup

Open the data-management area and export your database to a safe location.
